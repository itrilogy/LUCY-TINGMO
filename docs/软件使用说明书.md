## 1. 简介

### 1.1 软件是什么

**听默** 是安装在电脑上的语音成文工具。按下快捷键说话，软件在 **本机** 用语音识别模型把话转成文字，显示在悬浮窗（Overlay）中，并可复制或粘贴到您正在使用的其他软件（文档、聊天、邮件等）。

### 1.2 适用场景

- 口述记录、会议要点整理  
- 写作时语音输入  
- 需要 **数据留在本机** 的转写实验与生产辅助  

### 1.3 运行环境

| 项目 | 说明 |
| --- | --- |
| 系统 | macOS（10.15+）· Windows（x64）· Linux（x64） |
| 权限 | 麦克风；macOS 还需「辅助功能」以便粘贴到其他 App |
| 磁盘 | 模型文件体积较大（数百 MB～数 GB），请预留空间 |
| 网络 | 首次下载模型需要网络；纯离线使用需预先放好模型 |

## 2. 安装与启动

### 2.1 实验室分发安装（推荐用户路径）

1. 获取实验室提供的安装包（例如 macOS：`听默_x.y.z_*.dmg` 或 `听默.app`）。  
2. 将 **听默** 拖入「应用程序」文件夹（macOS）或按向导安装（Windows）。  
3. 从启动台/开始菜单打开 **听默**。  

> 本软件为实验室构建，**不是** App Store / Homebrew 上的「Handy」官方包。请勿混用品牌与更新源。

### 2.2 从源码构建（开发与维护人员）

```bash
# 依赖：Rust、Bun
bun install
mkdir -p src-tauri/resources/models
curl -o src-tauri/resources/models/silero_vad_v4.onnx \
  https://blob.handy.computer/silero_vad_v4.onnx
bun run tauri dev      # 开发
bun run tauri build    # 打包
```

详细平台依赖见仓库 `BUILD.md`。

### 2.3 首次启动

1. 阅读并完成 **麦克风** 等权限授权。  
2. 进入 **模型** 引导页：下载推荐模型或选择已有模型。  
3. 在 **通用** 中确认快捷键（可按个人习惯修改）。  
4. 试录一句短语音，检查 Overlay 是否出现文字。

## 3. 权限说明（重要）

### 3.1 麦克风

系统设置中允许 **听默** 使用麦克风，否则无法录音。

### 3.2 macOS 辅助功能

若需把文字 **自动粘贴** 到其他应用，请将听默加入：

**系统设置 → 隐私与安全性 → 辅助功能**

- 安装版路径一般为：`/Applications/听默.app`  
- 若使用开发构建，请添加实际运行的那个 `.app`，与安装版不是同一条目。  

修改权限后建议 **完全退出听默再打开**。

## 4. 界面导览

### 4.1 主窗口（设置）

侧栏主要分区：

| 分区 | 用途 |
| --- | --- |
| 通用 | 快捷键、按住说话、语言、主题、托盘、自启动等 |
| 模型 | 选择/下载/卸载语音模型 |
| 高级 | Overlay 形态、粘贴相关、音频反馈等 |
| 后处理 | 可选大模型润色 API 与提示词 |
| 历史记录 | 过往转写、重命名、重试、删除 |
| 调试 | 日志与路径（维护用） |
| 关于 | 版本、数据目录、听默与鹿溪标识 |

窗口标题与产品名显示为 **听默**；关于页展示 **鹿溪联合创新实验室** Logo。

### 4.2 系统托盘

- 显示当前状态（空闲 / 录音 / 转写）。  
- 菜单可打开设置、复制最近一次转写、卸载模型、退出等。  
- 实验室版本中「检查更新」通常为禁用状态。  

### 4.3 录制悬浮窗（Overlay）

根据设置可表现为：

- **关闭**：不显示悬浮窗  
- **药丸等紧凑形态**：占用小、适合长期开着  
- **直播/展开**：便于查看实时分段与结果全文  

结果态一般提供关闭、复制、粘贴到前台等操作（以当前版本 UI 为准）。

## 5. 基本操作流程

### 5.1 一次完整转写

1. 将光标放在目标输入框（若计划粘贴）。  
2. 按下（或按住）**转写快捷键** 开始录音。  
3. 清晰说话；结束快捷键或松开按键。  
4. 等待转写完成，在 Overlay 中查看文本。  
5. 按需 **复制** 或 **粘贴到前台**。  
6. 之后可在 **历史记录** 中再次打开该条。  

### 5.2 按住说话（Push-to-Talk）

在通用设置中开启后：按住快捷键录音，松开即停止并转写。适合短句输入。

### 5.3 取消

录音或转写过程中可通过设置的取消方式、托盘或命令行取消，避免错误内容写入。

### 5.4 长段发言

可连续说较长时间。软件会按模型能力 **自动分片** 转写。  
若使用对单次长度敏感的模型，过长时请依赖分片或分段说；历史中可对失败条目 **重新转写**。

## 6. 设置说明（常用）

### 6.1 快捷键

- 在「通用」中点击快捷键录入区，按下新组合键保存。  
- 避免与系统或其他软件冲突。  
- Linux Wayland 下全局键可能需在系统快捷键中绑定 CLI（见第 8 节）。  

### 6.2 模型选择建议

| 需求 | 建议 |
| --- | --- |
| 快、机器一般 | 较小 Whisper / 轻量 ONNX 类模型 |
| 更准、机器较好 | 中大尺寸 Whisper 等 |
| 中文场景实验 | 按实验室推荐目录选择 SenseVoice / Qwen3 等 |

模型文件位于应用数据目录的 `models/`，也可从 Hugging Face 缓存被扫描到（视实现与设置）。

### 6.3 Overlay 与粘贴

- 不需要悬浮窗时设为关闭，仍可通过历史与剪贴板使用结果。  
- 若粘贴内容变成「剪贴板里原来的旧文字」，请升级到含粘贴修复的版本，并确认辅助功能已授权。  
- 可调整粘贴延迟等高级项（调试/高级页）。  

### 6.4 历史记录

- **重命名标题**：便于日后查找。  
- **重新转写**：换模型或失败后重试。  
- **保留策略**：可配置历史条数与录音文件保留时间，避免占满磁盘。  

### 6.5 后处理（可选）

1. 填写 API 地址、模型与密钥。  
2. 编辑提示词（如：整理为要点、纠正专有名词）。  
3. 对单次转写或历史条目触发后处理。  

**注意：** 启用后，**文本**会发送到您配置的第三方服务，请遵守所在单位数据规范。

### 6.6 主题与语言

可在设置中切换界面语言与浅色/深色主题。产品 slogan 等品牌文案在中文环境下为「听而有迹·默而成文」。

## 7. 数据与文件位置

应用使用标识 **`com.pais.handy`** 作为数据目录名（为兼容历史数据，与产品显示名「听默」可以不同）。

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/com.pais.handy/` |
| Windows | `%APPDATA%\com.pais.handy\` |
| Linux | `~/.config/com.pais.handy/` |

常见内容：

| 文件/目录 | 含义 |
| --- | --- |
| `settings_store.json` | 设置 |
| `history.db` | 历史数据库 |
| `models/` | 模型 |
| `recordings/` | 录音（若开启保留） |

关于页可复制「应用数据目录」路径。  
日志（macOS 常见）：`~/Library/Logs/com.pais.handy/`。

**卸载注意：** 删除应用不一定删除上述数据；若需彻底清除请手动删除数据目录（删除前请备份）。

## 8. 命令行用法

二进制名：**`tingmo`**

```bash
tingmo --toggle-transcription    # 切换录音
tingmo --toggle-post-process     # 切换「带后处理」的录音
tingmo --cancel                  # 取消
tingmo --start-hidden            # 启动时不显示主窗口
tingmo --no-tray                 # 不显示托盘
tingmo --debug                   # 详细日志
tingmo --help
```

macOS 应用包内：

```bash
/Applications/听默.app/Contents/MacOS/tingmo --toggle-transcription
```

说明：上述参数作用于 **运行行为**，不会改写您在设置界面里保存的持久配置。

## 9. 常见问题

**Q1：按下快捷键没反应？**  
检查是否已在运行、快捷键是否冲突、辅助功能/输入监控权限是否授予。

**Q2：有声音但识别为空？**  
检查麦克风是否选对、系统音量/静音、VAD 是否过于严格、是否说话过短。

**Q3：识别乱码或特别短？**  
可能是模型不适合超长单段；换模型或依赖分片后 **历史里重新转写**；确认模型已完整下载。

**Q4：无法粘贴到微信/文档？**  
检查辅助功能权限；尝试先「复制」再手动粘贴；关闭可能抢焦点的 Overlay 形态做对比。

**Q5：模型下载失败？**  
检查网络与代理；可按关于页目录手动放入模型文件后重启（维护人员可参考研发文档）。

**Q6：是否自动更新？**  
实验室版默认 **不检查 / 不自动更新**。请使用实验室下发的安装包升级。

**Q7：和 Handy 是什么关系？**  
听默基于开源 Handy 改造并使用自有品牌，供实验室使用；不是 Handy 官方产品。
