## 1. 功能概述

### 1.1 软件用途

听默用于在 **个人计算机本机** 将用户语音转换为文本，服务于会议备忘、写作口述、实验记录、无键盘场景输入等场景。核心价值：**快捷键唤起、本地模型推理、结果可控输出、历史可追溯**。

### 1.2 用户角色

| 角色 | 说明 |
| --- | --- |
| 终端用户 | 配置设备与模型，使用快捷键完成转写 |
| 实验室维护者 | 构建安装包、管理模型与标识物词表、查阅日志 |

无多租户/云账号体系；配置与数据均在本机。

## 2. 功能详细说明

### F1 录音与转写

| 编号 | 功能点 | 描述 | 优先级 |
| --- | --- | --- | --- |
| F1.1 | 快捷键触发 | 用户可自定义全局快捷键；支持切换式或按住说话（Push-to-Talk） | 必须 |
| F1.2 | 音频采集 | 枚举并选择麦克风；采集过程可视化（电平/波形，视 Overlay 配置） | 必须 |
| F1.3 | VAD | 静音抑制；可选在段边界触发半实时转写并刷新 Overlay | 必须（半实时可选） |
| F1.4 | 本地 ASR | 使用已下载模型在本地完成语音到文本；支持目录中多种引擎/模型 | 必须 |
| F1.5 | 长音频分片 | 超过引擎有效窗时自动切段推理并拼接，降低超长单段失败率 | 必须 |
| F1.6 | 取消 | 快捷键/CLI/托盘等路径取消进行中的录音或转写 | 必须 |

**业务规则：**

- 无可用模型时引导 Onboarding 下载或选择模型。
- 无麦克风权限时提示授权，不进入有效录音。
- 转写失败时 Overlay/通知给出错误或空结果提示，不静默崩溃。

### F2 结果呈现与输出

| 编号 | 功能点 | 描述 |
| --- | --- | --- |
| F2.1 | Overlay | 可配置关闭 / 最小化药丸 / 直播展开等形态；录制中与结果态布局区分 |
| F2.2 | 复制 | 一键将结果写入系统剪贴板 |
| F2.3 | 粘贴到前台 | 将文本送入当前前台应用；实现上先更新剪贴板再触发粘贴，避免旧内容竞态 |
| F2.4 | 提示音 | 录音开始/结束等可开关与选音 |

**业务规则：**

- 粘贴方式可配置（含不自动粘贴、仅剪贴板等策略，以设置为准）。
- Lab 版本强调结果可控：默认交互可偏向展示 + 用户确认复制/粘贴（依设置项）。

### F3 模型管理

| 编号 | 功能点 | 描述 |
| --- | --- | --- |
| F3.1 | 模型目录 UI | 展示推荐与可用模型、精度/速度等说明（文案 i18n） |
| F3.2 | 获取模型 | 在线下载（网络允许时）或扫描本地/HF 缓存已有文件 |
| F3.3 | 生命周期 | 选择当前模型；手动卸载；空闲超时自动卸载 |
| F3.4 | 语言 | 自动/指定源语言；可选相关翻译类选项（视引擎能力） |

支持模型族（随目录扩展，示例）：Whisper 系列、Parakeet、SenseVoice、Qwen3-ASR 等。

### F4 历史记录

| 编号 | 功能点 | 描述 |
| --- | --- | --- |
| F4.1 | 浏览 | 时间序列列表；条目可折叠/展开长文本 |
| F4.2 | 标题 | 用户可重命名条目标题，便于检索 |
| F4.3 | 回放 | 若保留录音，可播放对应音频 |
| F4.4 | 重试 | 用当前模型重新转写；可触发后处理 |
| F4.5 | 治理 | 删除、收藏/固定、历史条数上限、录音保留周期 |

### F5 后处理与纠偏

| 编号 | 功能点 | 描述 |
| --- | --- | --- |
| F5.1 | 提供方配置 | API Base URL、模型名、密钥等（本地保存） |
| F5.2 | 提示词 | 用户可编辑后处理提示，用于润色/格式化 |
| F5.3 | 标识物 | 维护 ASR 易错词映射；支持导入导出（如 Markdown） |

**业务规则：** 后处理依赖外部服务时需用户明确配置；失败不影响已生成的原始转写文本落库（以实际错误处理为准，原始结果优先保留）。

### F6 系统与设置

| 编号 | 功能点 | 描述 |
| --- | --- | --- |
| F6.1 | 分类设置 | 通用、高级（Overlay、粘贴延迟、缓冲区等）、调试 |
| F6.2 | 托盘 | 显示/隐藏托盘；托盘菜单：设置、复制最近结果、卸载模型、退出等 |
| F6.3 | 外观 | 浅色/深色/跟随系统；UI 语言 |
| F6.4 | 权限 | 引导麦克风与辅助功能（平台相关） |
| F6.5 | 调试 | 日志级别、路径展示、部分实验开关；快捷键打开调试区 |

**Lab 特例：** 应用内「检查更新」默认禁用，不走 Handy 官方更新通道。

### F7 品牌与关于

| 编号 | 功能点 | 描述 |
| --- | --- | --- |
| F7.1 | 产品信息 | 显示听默名称、slogan、版本号、数据目录路径 |
| F7.2 | 开发者 | 鹿溪联合创新实验室名称、slogan、Logo；说明基于 Handy 的实验属性 |

### F8 集成接口

| 编号 | 功能点 | 描述 |
| --- | --- | --- |
| F8.1 | CLI | `tingmo` 支持 toggle / cancel / start-hidden / no-tray / debug |
| F8.2 | 单实例 | 已运行时再次启动用于投递控制参数或前置设置窗 |

## 3. 非功能特性

| 类别 | 说明 |
| --- | --- |
| 性能 | 轻量模型可在 CPU 使用；重模型建议更好 CPU/GPU；空闲可卸模型 |
| 可靠性 | 单实例；取消路径；长音频分片；粘贴校验 |
| 隐私 | 默认本地；可选第三方 API 由用户配置 |
| 可维护性 | 前后端分层；设置持久化；调试日志 |
| 国际化 | 多语言资源文件；中文品牌文案 |
| 兼容性 | macOS / Windows / Linux；数据目录兼容 Handy 标识以便迁移 |
