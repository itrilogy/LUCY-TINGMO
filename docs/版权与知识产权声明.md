## 4. 数据与隐私

4.1 默认场景下，录音与转写在 **用户本机** 完成，软件不将原始音频上传至本实验室服务器（本软件亦不运营必须联网的转写云服务）。

4.2 若用户自行配置 **外部大模型 / API 后处理**，文本（及用户配置的接口信息）将按用户设定发往第三方服务，适用该服务的隐私与条款，本实验室不对第三方服务承担责任。

4.3 应用数据默认存储于本机路径（标识 `com.pais.handy` 目录下的设置、历史库、模型与录音等），详见 [软件使用说明书](./软件使用说明书.md)。
