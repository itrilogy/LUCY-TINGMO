# 00 · 调研总览

## 1. 调研范围

| 维度 | 范围 |
|------|------|
| 源码 | 本仓库 Tauri 2 + React/TS 全栈 |
| 运行时证据 | macOS 安装版 `com.pais.handy` 日志、settings、WAV、history.db |
| 焦点 | 现场录制、VAD、模型管理、长音频转写失败/缩减 |

## 2. 与目标的匹配度

| # | 目标 | 现状 | 匹配度 |
|---|------|------|--------|
| 1 | 现场录制 + 选定模型转写 | 快捷键录音 → `TranscriptionManager.transcribe` / stream finalize；模型可选（catalog + UI） | **高** |
| 2 | 可选 VAD 实时分段，逐段半实时转写 | 有 VAD，但仅用于 **静音过滤 / 喂 stream**；**不会**把语音段切成独立 job 逐段转写后拼接 | **低～中** |
| 3 | 长录音内容大幅缩减 | 日志 + WAV 实锤：超长 PCM 整段喂给 SenseVoice（~30s 训练窗），结果严重退化 | **已定位** |

## 3. 核心结论

### 3.1 已做好的

1. **多引擎 ASR 门面**：`TranscriptionManager` + `EngineType`（transcribe-cpp GGUF + transcribe-rs ONNX）。
2. **现场录制闭环**：`TranscriptionCoordinator` → `TranscribeAction` → 录音 → 转写 → 粘贴 → history。
3. **Silero VAD + 平滑**：onset / hangover / prefill；可开关（`vad_enabled`）。
4. **部分模型 live streaming**（transcribe-cpp `supports_streaming`）。
5. **模型下载/缓存/能力探测**（catalog + HF + mirror）。

### 3.2 关键缺口（对应目标 1/2）

| 缺口 | 说明 |
|------|------|
| **无长音频分片编排** | `session.run(&audio)` / `transcribe(&audio)` 一次吞全量；不读 `max_audio_ms` |
| **VAD ≠ 分段转写** | VAD 只决定「帧是否进入 buffer」；不是「一段结束 → 提交一段 ASR → 累积文本」 |
| **无半实时分段 UI/协议** | Live stream 是模型内部 stream API，不是应用层 segment pipeline |
| **模型能力未驱动策略** | 日志已提示 `Split long audio into <=30 s segments`，应用层未实现 |

### 3.3 安装版实锤（详见 06）

| 会话 | 音频时长 | 模型 | 结果 |
|------|----------|------|------|
| history #6 | **1054.6s**（17.6 min） | SenseVoiceSmall Q8 | ~5.8k 字，质量中等偏糊，引擎 WARN 超 30s |
| history #7 | **1808.1s**（30.1 min） | SenseVoiceSmall Q8 | **仅 ~1.5k 字**，严重乱码重复（「标标标」「司司」） |

短录音（2–9s）在 SenseVoice / Qwen3 上均正常。

## 4. 问题优先级（建议）

| 优先级 | 问题 | 影响 |
|--------|------|------|
| P0 | 超 `max_audio` 不分片直接跑 | 长录音内容丢失/乱码；内存二次方增长风险 |
| P0 | 应用层无「VAD 段 → 逐段 ASR → 拼接」 | 无法满足目标 2 的半实时分段 |
| P1 | Stream 非空即采用、跳过 batch | 流式模型长会话可能用半成品文本 |
| P1 | Stream feed 失败仅 warn、finalize 30s 超时无 batch 回退 | 偶发失败/空结果 |
| P2 | 无前端上传音频 UI（仅 CLI `-f`） | 离线文件场景不便 |
| P3 | history limit / retention 导致复盘样本少 | 取证受限 |

## 5. 推荐产品形态（对齐目标）

> 交互已拍板（见 `08` v1.1）：**不自动粘贴** · **分段半实时默认关** · **扩大 overlay**

```
模式 A · 录完再转（Batch，默认）
  录制 →（可选 VAD 去静音）→ 按 max_audio 分片 → 逐片 ASR → 拼接
  → 扩大 overlay 展示 + 用户「复制」（不自动粘贴）

模式 B · 半实时分段（Segmented，默认关）
  录制中 → VAD 段结束 → 段 ASR → overlay 追加文本
  停止时 → 冲刷尾段 → 用户「复制」

模式 C · 模型原生 Stream（仅 supports_streaming）
  帧级 feed → overlay 预览
  结束建议与 auto_split 校验兜底
```
