# 02 · 代码文件用途

路径均相对于仓库根目录。

---

## 1. 后端入口与编排（`src-tauri/src/`）

| 文件 | 用途 |
|------|------|
| `main.rs` | 二进制入口，解析 CLI |
| `lib.rs` | Tauri 应用组装、Manager 初始化、插件、命令注册、headless `--transcribe-file` |
| `cli.rs` | clap CLI 定义（toggle / cancel / debug / transcribe-file / list-models…） |
| `actions.rs` | **录制开始/停止与转写主流程**；post-process LLM；OpenCC 简繁；粘贴输出 |
| `transcription_coordinator.rs` | 快捷键事件串行化，消除竞态（debounce / PTT release grace） |
| `signal_handle.rs` | 信号与 CLI 复用的 `send_transcription_input` |
| `settings.rs` | `AppSettings` 结构、默认值、读写 store、schema 迁移 |
| `clipboard.rs` | 剪贴板读写与粘贴策略 |
| `input.rs` | 文本注入 / 打字相关 |
| `overlay.rs` | 录制/转写/流式 overlay 窗口控制 |
| `tray.rs` / `tray_i18n.rs` | 托盘图标状态与菜单 |
| `llm_client.rs` | 后处理 LLM HTTP 客户端（OpenAI 兼容等） |
| `apple_intelligence.rs` | macOS Apple Intelligence 桥接 |
| `portable.rs` | 便携模式数据目录 |
| `utils.rs` | 平台检测、取消、overlay 辅助 |
| `helpers/clamshell.rs` | Mac 开合盖麦克风切换探测 |

---

## 2. Managers（业务核心）

| 文件 | 用途 |
|------|------|
| `managers/mod.rs` | 模块导出 |
| `managers/audio.rs` | **录音生命周期**、静音边录、lazy close、设备缓存、VAD 策略接入 |
| `managers/transcription.rs` | **ASR 引擎加载/卸载/batch/stream**、StreamRouter、性能日志 |
| `managers/model.rs` | 模型目录、下载（URL/HF）、磁盘状态、自定义模型 |
| `managers/model/download.rs` | 下载实现（断点、SHA、stall 超时） |
| `managers/model_capabilities.rs` | GGUF 能力探测（streaming / translate / languages） |
| `managers/gguf_meta.rs` | GGUF 元数据读取辅助 |
| `managers/history.rs` | history.db + recordings 目录、保留策略、重试 |

---

## 3. Audio Toolkit

| 文件 | 用途 |
|------|------|
| `audio_toolkit/mod.rs` | 公共 re-export |
| `audio_toolkit/constants.rs` | `WHISPER_SAMPLE_RATE = 16000` |
| `audio_toolkit/audio/recorder.rs` | **cpal 采集 worker**、Start/Stop/Shutdown、VAD 帧处理、audio_cb |
| `audio_toolkit/audio/device.rs` | 输入设备枚举 |
| `audio_toolkit/audio/resampler.rs` | 设备采样率 → 16kHz 帧重采样 |
| `audio_toolkit/audio/visualizer.rs` | 频谱电平 → 前端电平条 |
| `audio_toolkit/audio/utils.rs` | WAV 读写/校验等 |
| `audio_toolkit/vad/mod.rs` | VAD 常量（prefill/hangover/onset）与 trait |
| `audio_toolkit/vad/silero.rs` | Silero 30ms 帧推理 |
| `audio_toolkit/vad/smoothed.rs` | 平滑：起说确认、句尾 hangover、prefill 回填 |
| `audio_toolkit/text.rs` | 自定义词模糊纠正、filler 过滤、stutter 折叠 |
| `audio_toolkit/bin/cli.rs` | audio toolkit 独立 CLI（调试用） |

## 4. Commands（前端 IPC）

| 文件 | 用途 |

## 7. 前端（`src/`）

| 路径 | 用途 |
|------|------|
| `main.tsx` / `App.tsx` | 入口与主界面（onboarding / 设置 shell） |

| `hooks/useSettings.ts` | 设置读写 hook |
| `components/settings/**` | 各设置项（VAD、模型、后处理、快捷键…） |
| `components/model-selector/**` | 模型选择与下载 UI |
| `components/onboarding/**` | 首次运行引导 |
| `components/settings/history/**` | 历史回放/重试 |
| `overlay/**` | 独立录制 overlay 窗口前端 |
| `i18n/**` | 多语言；英文为源文案 |
| `lib/utils/**` | 格式化、主题、键盘、模型文案 |

## 9. 与目标相关的「必读」文件清单

若只改目标 1/2/长音频：

1. `managers/transcription.rs` — 推理入口  
2. `managers/audio.rs` + `audio_toolkit/audio/recorder.rs` + `vad/*` — 录音与 VAD  
3. `actions.rs` — stop 后采用 stream 还是 batch  
4. `transcription_coordinator.rs` — 生命周期  
5. `managers/model_capabilities.rs` + catalog — 模型能力（`max_audio` 应接入）  
6. `settings.rs` + `VoiceActivityDetection.tsx` — 用户开关  
7. `commands/history.rs` — 文件重试路径
