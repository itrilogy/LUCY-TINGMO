# 04 · 数据流与管线

## 1. 主路径：现场录制 → 转写 → 粘贴

```text
[用户按 Option+Space]
        │
        ▼
TranscriptionCoordinator::Input(pressed)
        │
        ▼
TranscribeAction::start
  ├─ ModelManager 确认模型 / kickoff load
  ├─ 判断 supports_streaming → 可选 start_stream
  ├─ 选择 VadPolicy (Disabled|Offline|Streaming)
  ├─ show overlay / tray Recording
  └─ AudioRecordingManager::try_start_recording
            │
            ▼
     AudioRecorder worker
       cpal callback → samples channel
       FrameResampler → 16kHz / 30ms
       SmoothedVad?
         Speech → processed_samples += frame
                → StreamRouter.feed(frame)   # 若 stream open
         Noise  → drop
            │
[用户再按 Option+Space 停止]
            │
            ▼
TranscribeAction::stop
  ├─ tray Transcribing
  ├─ remove_mute + stop sound
  └─ async:
       samples = stop_recording()
       save_wav(samples)  // 并行
       text = finalize_stream() 非空 ? stream
             : transcribe(samples)   // batch
       process_transcription_output (OpenCC / LLM)
       paste + history
```

## 2. 半实时 Live Stream 路径（仅部分模型）

```text
start_stream:
  后台 worker 取走 LoadedEngine
  session.stream(run_options)

feed:
  每 30ms speech 帧 → stream.feed
  → StreamTextEvent { committed, tentative } → overlay

finalize:
  stream.finalize → display text
  引擎归还
```

**与目标 2 的差异：**

| 维度 | 当前 Live Stream | 目标「VAD 分段半实时」 |
|------|------------------|------------------------|
| 触发 | 每帧 feed | 语音段结束事件 |
| 文本 | 模型内部 committed/tentative | 应用层段文本拼接 |
| 模型要求 | 必须 supports_streaming | 任意 batch 模型也可 |
| 失败处理 | 半成品可能当最终结果 | 可按段重试 |

## 3. 文件转写路径

```text
CLI: handy -f file.wav [--model id]
  → headless load model
  → read_wav_samples
  → transcribe(samples)   # 无 VAD
  → 打印 / JSON 退出
```

前端 **无** 上传 UI；历史重试走 `commands/history.rs`。

## 5. 内存与数据量估算

16 kHz mono f32：

| 时长 | 样本数 | 约内存 |
|------|--------|--------|
| 30 s | 480_000 | ~1.9 MB |
| 5 min | 4.8M | ~19 MB |
| 17.6 min | 16.9M | ~64 MB f32 / ~32 MB WAV(s16) |
| 30.1 min | 28.9M | ~110 MB f32 / ~55 MB WAV(s16) |

与本机 `recordings/` 中两段长 WAV 一致（见 06）。

## 6. 并发与锁

| 资源 | 策略 |
|------|------|
| 录音 state | Mutex + cancel_generation |
| 引擎 | Mutex；stream 时 take 出 lease |
| 模型加载 | is_loading + Condvar |
| Coordinator | 单线程 mpsc |
| Stream feed | 无界 channel（背压风险：慢模型时内存涨） |
