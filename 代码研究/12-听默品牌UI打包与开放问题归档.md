## 2. 功能与 UI 改动摘要（本轮）

### 2.1 Overlay / 半实时

| 项 | 行为 |
|----|------|
| 分段显示 | `join_display_segments` **按段换行**（累计/结果/历史文本） |
| 展开尺寸 | 录制中「展开」与结果窗 **同宽高 token**（`--ov-result-w` / `--ov-result-cap-max-h`） |
| 原生窗 | streaming 与 result 共用 `OVERLAY_PANEL_*`（420×220 logical） |
| 展开动画 | 宽 + 文本区 max-height ~420ms |
| 初始无语音 pill | 三列对称：`[点 \| 波形 \| 关闭]` |
| 关闭按钮 | live-bar 右侧贴边；结果空态为「× + 关闭」合一按钮 |
| 空结果 | 「未识别到语音…」与结果窗同外框高度；文案居中 |

### 2.2 粘贴到前台

| 问题 | 剪贴板已有内容时，易粘贴旧内容 / 写后立刻 restore 竞态 |
| 修复 | `paste_to_frontmost`：先写再贴、**不恢复旧剪贴板**、校验重写、延迟下限；`PasteMethod::None` 显式粘贴时回落默认 |

关键：`src-tauri/src/clipboard.rs`、`commands/transcription.rs`。

### 2.3 更新入口

| 位置 | 状态 |
|------|------|
| 页脚检查更新 | **强制置灰** |
| 托盘检查更新 | **enabled: false** |
| 调试开关 | disabled + 强制关 |
| 默认 `update_checks_enabled` | `false` |
| 原因 | lab 不跟上游 Handy updater；且无私钥 |

### 2.4 标点管线（前期已落地，记入备忘）

- L1 停顿标点（live 段）  
- L2 启发式 / 预留 ONNX（batch/段）  
- L3 历史 LLM 后处理  

详见 `text_punctuate.rs`、`segment_pipeline.rs`。

## 3. 打包与运行（本机 macOS 记录）

### 3.1 成功产物（2026-07-31 左右）

```text
src-tauri/target/release/tingmo
src-tauri/target/release/bundle/macos/听默.app
src-tauri/target/release/bundle/dmg/听默_0.9.4_aarch64.dmg
src-tauri/target/release/bundle/macos/听默.app.tar.gz   # updater 中间物
```

### 3.2 警告 / 错误是否影响

| 日志 | 影响 |
|------|------|
| Apple Intelligence stubs（仅 CLT） | **不影响**主功能与打包 |
| Signing identity `-`（ad-hoc） | 可装；**未公证** |
| skipping notarization | 预期；他人机可能需右键打开 |
| `TAURI_SIGNING_PRIVATE_KEY` missing | **.app/.dmg 已生成**；仅 updater 签名失败导致 CLI exit 1 |
| `createUpdaterArtifacts: true` + 无私钥 | 同上；lab 可后续关掉 |

### 3.3 辅助功能授权（已验证有效）

1. 列表中删除所有 Handy / tingmo / 听默 / 空白项  
2. 只保留 **`/Applications/听默.app`**（加整个 **.app**，不是 `Contents/MacOS/tingmo`）  
3. 打开开关 → 完全退出再开  

开发版与安装版 **TCC 权限不共用**。

### 3.4 数据目录（重要）

```text
~/Library/Application Support/com.pais.handy/
~/Library/Logs/com.pais.handy/   # 若有日志
```

| 现象 | 解释 |
|------|------|
| 新装听默仍有模型/历史 | **合理**：`identifier` 仍为 `com.pais.handy`，有意共用 |
| 真·空白安装 | 退出应用后删除/挪走上述 Application Support 目录 |

应用内：**关于 → 应用数据目录** 可打开。
