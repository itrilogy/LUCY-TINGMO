## 用户目标（本调研对齐基准）

1. **现场录制** → 用选定模型做离线/准实时转写（转义）
2. **可选 VAD 实时分段** → 逐段半实时转写
3. **解析当前代码问题** → 尤其是长录音结束内容大幅缩减/出错

## 一句话结论

**演进后（lab）**：已具备长音频自动分片、可选 VAD 半实时、结果 overlay 复制（不自动粘贴）、标识物纠偏与轻量 Session 编排。  
安装版历史问题：`SenseVoice` 对超长整段音频告警 *beyond the ~30 s window* 导致缩减/乱码——见 `05`/`06`；修复验证见 `fixtures/*-regression-report.md` 与 `11` 手测清单。
