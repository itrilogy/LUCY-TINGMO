## 1. 前置条件

### 1.1 构建与模型

```bash
# 依赖
bun install
mkdir -p src-tauri/resources/models
# 若无 VAD 模型：
# curl -o src-tauri/resources/models/silero_vad_v4.onnx https://blob.handy.computer/silero_vad_v4.onnx

# 开发运行（macOS cmake 问题时）：
CMAKE_POLICY_VERSION_MINIMUM=3.5 bun run tauri dev
```

### 1.2 建议模型

| 场景 | 模型 | 备注 |
|------|------|------|
| 中文长录 / 分片 | SenseVoice Small GGUF | 验证 ~30s 窗 |
| 半实时 | 任意本地模型 + 模式「分段半实时」 | 不依赖 native stream |
| native stream（可选） | 带 Streaming 徽章的模型 | batch 模式下会走 `native_stream` session mode |
| LLM 纠偏 | 已配置 post-process provider + 「ASR Domain Correction」prompt | 需 API key / 本地 LLM |

### 1.3 日志位置

- macOS：`~/Library/Logs/com.pais.handy/`（或 Debug 面板 Live Logs）  
- 关键日志键：`session_id=` `mode=` `event=` `auto_split` `VAD segment force-cut` `ASR marker rules applied`

### 1.4 设置基线（手测前）

| 设置 | 推荐值（首轮） |
|------|----------------|
| 转写模式 | **录完再转（自动分片）** |
| VAD 过滤 | 开（与半实时无关时可关做对照） |
| 标识物规则替换 | **开** |
| 注入 glossary | **开** |
| 自动确认 LLM 新词 | **关** |
| Overlay | Minimal 或 Live |
| 后处理 | 首轮关；T5 再开 |
